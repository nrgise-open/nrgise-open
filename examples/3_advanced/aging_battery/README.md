# Aging Battery

In this example, we use a predefined profile of control actions that the battery must execute.
This is used, among other things, to study the aging of a battery under a predefined usage profile.
In the result files, you can observe the respective share of calendar and cyclic aging that occured, and how the battery capacity changed due to aging.
(Uncomment the code at end of aging_battery.py to store the results)
